# 🚀 AI Study Chatbot (Offline)

An offline AI-powered chatbot built with **Python**, **Streamlit**, and **Ollama (TinyLLaMA)**. It helps students with **DSA**, **DBMS**, and **technical interview preparation** without requiring an internet connection or paid AI APIs.

## 🔥 Features

- 💬 Chat with AI completely offline
- 🧠 Maintains conversational memory during the session
- 📚 Assists with DSA, DBMS, and interview preparation
- ⚡ Fast local inference using Ollama (TinyLLaMA)
- 💰 No API costs or cloud dependency

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- TinyLLaMA
- Requests

## ▶️ Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start Ollama:

```bash
ollama serve
```

Run the chatbot:

```bash
streamlit run app.py
```
